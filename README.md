# Guitar Looper

YouTube 기타 카피를 위한 브라우저 기반 AB 반복 도구입니다. 저장된 AB 구간은 브라우저 `localStorage`의 `guitar-looper-v1` 키에만 저장되며, IN & OUT 데이터와 분리됩니다.

## 단축키

`[` A 지정 · `]` B 지정 및 반복 · `\` 자유재생 · `←`/`→` 5초 이동 · `Backspace` A로 이동 · `Space` 재생/일시정지

YouTube iframe은 상위 페이지의 키보드 이벤트를 직접 전달하지 않는 브라우저 보안 제한이 있습니다. 영상 클릭 뒤 단축키가 작동하지 않으면 화면의 **키보드 제어** 버튼을 누르거나 영상 바깥을 클릭하세요. 전체화면에서는 앱 컨테이너가 포커스를 관리하고 하단 대체 제어 버튼을 제공합니다.
